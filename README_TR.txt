SOKAK ŞAMPİYONU — ANDROID PROJESİ

Bu paket, verilen HTML futbol oyununu Android WebView uygulamasına sarar ve dokunmatik kontroller ekler.

APK oluşturma:
1. Android Studio'yu bilgisayarınıza kurun.
2. File > Open ile bu klasörü açın.
3. Android SDK Platform 35 ve Android Gradle Plugin bağımlılıklarının indirilmesine izin verin.
4. Build > Build Bundle(s) / APK(s) > Build APK(s) seçin.
5. APK genellikle app/build/outputs/apk/debug/app-debug.apk yolunda oluşur.

Not: Bu ortamda Android SDK/Gradle derleme ortamı bulunmadığından APK ikilisi burada derlenmedi. Bu kaynak proje Android Studio ile derlenmek üzere hazırlandı. Oyun içindeki mevcut CDN tabanlı Tailwind, Tone.js ve Google Fonts kaynakları ilk açılışta internet bağlantısı gerektirebilir.
